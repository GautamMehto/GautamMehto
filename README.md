# 💫 About Me

🚀 **React Developer** with **2+ years of experience** building responsive, scalable web applications using **React.js**, **JavaScript**, and **Tailwind CSS**.

I specialize in translating **Figma UI/UX designs** into clean, reusable component-based interfaces — with a strong eye for cross-browser compatibility, mobile-first responsiveness, and performance. At **iDevLive**, I've worked across the full frontend lifecycle — from landing pages and dashboards to REST API integration with backend teams using PHP and Laravel.

Beyond the core stack, I bring hands-on experience with **GSAP** and **Framer Motion** to build interfaces that don't just work — they feel good to use.

- 🔭 Currently working as **Frontend Developer & UI Designer** at iDevLive
- 🌱 Currently leveling up in **TypeScript**, **Redux Toolkit**, and **Next.js**
- 💬 Ask me about **React.js**, **Tailwind CSS**, **Figma**, or **REST API Integration**
- 📫 Reach me at **1mehetogautam@gmail.com**
- 📍 Based in **New Delhi, India**
